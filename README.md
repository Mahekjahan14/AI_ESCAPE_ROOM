# AI Escape Room (Streamlit)

An interactive AI-inspired escape room game built using Streamlit.

## Features
- Multiple themed rooms
- Hint-based guessing gameplay
- Score system
- Lives system
- Session state management

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
